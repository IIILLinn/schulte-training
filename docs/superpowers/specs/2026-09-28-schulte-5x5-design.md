# 舒尔特训练网页设计（v2）

## 目标

制作一个可直接在浏览器中运行的舒尔特训练网页。用户可选择方形、圆形或不规则棋盘，按从小到大的顺序完成训练，并查看完整成绩反馈。网页同时发布到 GitHub Pages，任何人可通过公网链接直接打开。

## 棋盘类型

### 方形

- 尺寸：3×3、4×4、5×5、6×6、7×7。
- 数字内容：1 到 N²。
- 排列：数字随机分布到规则网格中。

### 圆形

- 数字个数：15、20、25、30、35、40、45、50。
- 数字内容：1 到 N。
- 排列：数字随机散布在圆形区域内，每次开始训练重新生成。
- 保持明显可见的圆形边界，内部位置、间距和局部密度尽量随机。

### 不规则形状

- 数字个数：15、20、25、30、35、40、45、50。
- 数字内容：1 到 N。
- 排列：每次开始训练随机生成不同轮廓和位置，混乱程度尽量高。
- 使用随机凹凸轮廓，与圆形形成明显视觉差异。
- 所有数字必须保持在棋盘范围内，格子互不重叠，且保留可点击间距。

## 点击规则

- 所有棋盘统一从小到大点击：1→2→3→…→N。
- 不提供“顺序排列”“倒序”等无意义选项。
- 圆形和不规则布局中，顺序相邻的数字（1 和 2、2 和 3……）必须尽量拉开距离，不能靠得太近。
- 点击正确数字时只显示短暂反馈，反馈结束后恢复普通外观，不保留永久高亮。
- 点击错误数字时短暂显示错误反馈，错误次数加 1。

## 页面结构

- 顶部：标题、简短训练说明。
- 设置区：棋盘尺寸、棋盘形状、快捷预设。
- 状态栏：实时用时、当前目标、错误次数、完成进度。
- 主区域：方形、圆形或不规则数字棋盘。
- 控制区：开始训练、重新开始、返回设置、清除记录。
- 成绩区：本局用时、错误数、当前规格最佳成绩、最近 5 次训练记录。

## 视觉与体验

- 米白背景、深色棋盘、清晰的高对比数字。
- 圆形和不规则格子允许轻微大小差异和随机圆角，增加形态变化，但不得影响点击。
- 错误反馈使用短促的颜色和位移动效，并遵循 `prefers-reduced-motion`。
- 桌面和手机宽度下均可正常完成训练；手机端不产生横向滚动。

## 数据规则

- 最佳成绩按具体规格区分：例如 `square-7x7`、`circle-30`、`irregular-50`。
- 最近记录最多保留 5 条，每条包含规格、用时、错误数和完成时间。
- 清除记录后，最佳成绩和最近记录同时重置。

## 验收标准

- 方形支持 3×3 至 7×7；圆形和不规则支持 15 至 50 的数字个数。
- 所有棋盘生成的数字无重复、无遗漏。
- 圆形显示圆形边界；不规则显示随机凹凸轮廓。
- 圆形和不规则每次重新开始都会产生新的随机布局。
- 任意两个格子不重叠；顺序相邻数字之间保持明显距离。
- 正确点击只短暂反馈，随后恢复正常外观。
- 计时、目标推进、错误统计和进度状态一致。
- 完成一局后对应规格的最佳成绩与历史记录即时更新，刷新页面后仍保留。
- GitHub Pages 公网地址可正常打开并完成训练。
